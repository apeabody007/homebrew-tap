# apeabody007/tap

Homebrew formulae for my tools.

```
brew install apeabody007/tap/redline
```

## redline

A floating CPU, GPU, memory and die temperature readout for Apple Silicon
Macs, with a warning when macOS starts thermal throttling.
[Source and screenshots.](https://github.com/apeabody007/redline)

It is built from source on your machine rather than downloaded as a binary.
Locally compiled code is never quarantined by Gatekeeper, so this needs no
Developer ID certificate and no notarization, and anyone who has Homebrew
already has the Command Line Tools it compiles with.
